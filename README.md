# 内在动物园

一个受 IFS（内在家庭系统）概念启发的原创娱乐性情景小测试。回答 20 道日常情景题，看看最近哪些“内在保护者”比较忙。

**不是心理测评工具，不用于诊断，也不是 IFS Scale 的翻译或简化版。** 结果只描述状态与保护方式，不提供诊疗建议。

## 使用与构建

- 网站：<https://zyrobbie.github.io/inner-zoo/>
- Node.js 22：`npm run build`，生成 `dist/`。
- 将完整 `dist/` 作为静态网站托管；不要只复制 HTML，头像在同级 `assets/avatars/`。
- 产品无 npm 运行时依赖、后端、账号或第三方字体。答题状态仅保留在当前页面内存中。

## 验证与发布

`qa-browser/` 使用锁定版本的 Playwright，在 Chromium、WebKit 及移动视口仿真中验证流程、布局与资源。详见其 README。移动视口仿真不等于真机测试。

GitHub Actions 只在本仓库的 `main` 分支发布：先构建并通过内容与完整资源检查，再将 `dist/` 部署到 GitHub Pages，最后核对线上提交标识与全部 20 个网站文件的 SHA-256。当前版本先发布供人工验收；浏览器自动化保留为独立手动工作流，不阻塞发布，也不代表已通过。工作流采用标准 Ubuntu runner；仅部署任务拥有 Pages 写权限。

源码、测试与发布资源在本仓库公开；原始工作文档与内部记录不在此仓库。

## V0.5

采用温柔绘本封面与六位保护者的确认版头像，保留原有问卷内容与计分规则。结果页主角色独立展示，其余角色使用紧凑横向卡片。

结果页可生成含测试二维码的高清 PNG。手机浏览器通过系统分享菜单或长按图片选择保存；网页不能绕过系统权限直接写入相册。生成与保存过程在本机进行，不上传答题结果。

轻量校验：`node qa-browser/scripts/preflight.cjs`、`node qa-browser/scripts/model-v05.cjs .`、`node scripts/test-export.cjs`。后两项是模型与绘制契约检查，不代替真实浏览器及手机保存验收。
